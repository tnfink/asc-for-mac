# AI Task Definition of Done

This document lists the criteria every AI task in `aitasks/` must fulfill **before it can be
marked as `done`**, in addition to the task's own acceptance criteria. The skill
`implement-task` checks them before completing a task.

## Criteria

- [ ] **The documentation is updated.** All documentation affected by the task reflects the new
      state of the project: the technical documentation in `doc/`, `README.md`, and the AI docs
      (`AGENTS.md`, skills in `skills/`) if the task changes the structure, conventions or way of
      working. Check by comparing the changes made in the task with the documents describing them.

## Changing this document

Add new criteria as checklist items in the section above. Each criterion must be verifiable,
preferably by a command or an inspection, so that humans and AI agents come to the same result.
