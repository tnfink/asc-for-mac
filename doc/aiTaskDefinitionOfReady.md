# AI Task Definition of Ready

This document lists the criteria an AI task in `aitasks/` must fulfill **before work on it can
start**. A task that does not fulfill all criteria must be completed first, e.g. with the skill
`improve-task` (see `doc/swDevelopmentProcess.md`), or with the help of the user.

## Criteria

- [ ] **Acceptance criteria are defined.** The section *Acceptance criteria* of the task contains
      at least one concrete, verifiable criterion; placeholder comments do not count.

## Changing this document

Add new criteria as further checklist items above. Each criterion must be checkable by reading
the task file, so that humans and AI agents come to the same result.
